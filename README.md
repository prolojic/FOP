## Регламент (кратко)

1. Параметры добавляются **только через Revit** (Управление → Общие параметры → Изменить) — файлы в формате UTF-16, вручную не править. Коммит: «Добавлен параметр <ИМЯ> (<группа>)».
2. Перед работой — `git pull`, после — `git push` и оповещение команды.
3. Локальные копии на сетевых дисках не использовать. Полная инструкция — `docs/Инструкция_ФОП_Git.pdf`.

## Утилита FopTools (C#)

Запуск из корня репозитория:

```bash
dotnet run --project FopTools -- check    # проверить центральный ФОП
dotnet run --project FopTools -- check <файл>   # проверить файл против центрального
```

Команда **`check`** — валидация центрального `FOP_SP_v2.txt`: формат файла,
дубли GUID и имён, ссылки на группы; дополнительные файлы сверяются
с центральным по GUID, имени и типу. Код выхода 0 — ошибок нет, 1 — есть ошибки.

Также проект открывается и собирается в Visual Studio как обычное
консольное приложение (net8.0, без внешних NuGet-зависимостей).

## Как добавить новый параметр

```bash
git pull
# отредактируйте FOP_SP_v2.txt (через Revit: Управление → Общие параметры → Изменить)
dotnet run --project FopTools -- check     # проверка
git add FOP_SP_v2.txt
git commit -m "Добавлен параметр <ИМЯ> (<группа>)"
git push
```
