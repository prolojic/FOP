# FOP — общие параметры Revit (регламент работы)

## Структура

| Путь | Что это | Кто правит |
|---|---|---|
| `SharedParameters.txt` | **Центральный ФОП** — единственный источник истины | команда, через коммиты |
| `fops/*.txt` | Производные фирменные ФОПы | **никто** — только генератором |
| `fops/FOP_HospitalTechnic.txt` | ФОП компании Hospital Technic (745 парам., ведётся отдельно) | отдельно, по согласованию |
| `FopTools/` | Консольная утилита (C#, .NET 8): генерация и валидация ФОПов | BIM-координатор |
| `fop_rules.json` | Правила отбора параметров в фирменные ФОПы | BIM-координатор |
| `.gitattributes` | Настройка Git для UTF-16 (чтобы видны diff) | — |

## Утилита FopTools (C#)

Запуск из корня репозитория:

```bash
dotnet run --project FopTools -- build    # пересобрать производные ФОПы
dotnet run --project FopTools -- check    # проверить все ФОПы в fops/
dotnet run --project FopTools -- check fops/FOP_ADSK.txt   # один файл
```

Команды:

- **`build`** — читает центральный `SharedParameters.txt` и `fop_rules.json`,
  пересобирает все фирменные ФОПы в `fops/` (перенумерация групп, порядок
  параметров сохраняется).
- **`check`** — валидация: формат файла, дубли GUID и имён, ссылки на группы,
  соответствие производных ФОПов центральному (по GUID, имени и типу).
  Код выхода 0 — ошибок нет, 1 — есть ошибки. Для отдельно ведомых файлов
  (`standalone` в `fop_rules.json`) дубли имён — предупреждения, не ошибки.

Также проект открывается и собирается в Visual Studio как обычное
консольное приложение (net8.0, без внешних NuGet-зависимостей).

## Правила для команды

1. **Параметры добавляются ТОЛЬКО в `SharedParameters.txt`** в этом репозитории.
   Никаких правок `fops/*.txt` руками — они перезаписываются генератором.
2. Перед коммитом запустите `dotnet run --project FopTools -- check` —
   команда должна пройти без ошибок.
3. После изменения центрального ФОПа запустите `build` и коммитьте
   центральный ФОП и пересобранные `fops/*.txt` одним коммитом
   с понятным сообщением (какие параметры добавлены).
4. В Revit подключайте свой фирменный ФОП из `fops/`, но добавлять новые
   параметры в него нельзя — переносите в центральный и пересобирайте.
5. Локальные копии на сетевых дисках (`Z:\FOP\revit-shared-parameters` и т.п.)
   вне обращения. Единственный актуальный файл — в этом репозитории.

## Как добавить новый параметр

```bash
git pull
# отредактируйте SharedParameters.txt (через Revit: Управление → Общие параметры → Изменить)
dotnet run --project FopTools -- check     # проверка
dotnet run --project FopTools -- build     # пересборка производных
git add SharedParameters.txt fops/
git commit -m "Добавлен параметр <ИМЯ> (<группа>)"
git push
```

## Правила отбора в fop_rules.json

Условие отбора (хотя бы одно): `namePrefix` — префикс имени параметра,
`groupExact` — точное имя группы, `groupPrefix` — префикс имени группы.
