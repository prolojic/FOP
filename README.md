# FOP — общие параметры Revit (регламент работы)

## Структура

| Путь | Что это | Кто правит |
|---|---|---|
| `SharedParameters.txt` | **Центральный ФОП** — единственный источник истины | команда, через коммиты |
| `fops/*.txt` | Производные фирменные ФОПы | **никто** — только генератором |
| `fops/FOP_HospitalTechnic.txt` | ФОП компании Hospital Technic (745 парам., ведётся отдельно) | отдельно, по согласованию |
| `build_fops.py` | Генератор производных ФОПов из центрального | BIM-координатор |
| `check_fops.py` | Валидация: формат, дубли GUID/имён, соответствие центральному | все, перед коммитом |
| `.gitattributes` | Настройка Git для UTF-16 (чтобы видны diff) | — |

## Правила для команды

1. **Параметры добавляются ТОЛЬКО в `SharedParameters.txt`** в этом репозитории.
   Никаких правок `fops/*.txt` руками — они перезаписываются генератором.
2. Перед коммитом запустите `python check_fops.py` — скрипт должен пройти без ошибок.
3. После принятия коммита с изменением центрального ФОПа запускается
   `python build_fops.py` и изменения коммитятся вместе с ним (один коммит = ФОП + пересобранные производные).
4. В Revit подключайте свой фирменный ФОП из `fops/`, но добавлять новые параметры в него
   нельзя — переносите в центральный и пересобирайте.
5. Локальные копии на сетевых дисках (`Z:\FOP\revit-shared-parameters` и т.п.) —
   вне обращения. Единственный актуальный файл — в этом репозитории.

## Как добавить новый параметр

```bash
git pull
# отредактируйте SharedParameters.txt (через Revit: ФОП → Изменить)
python check_fops.py            # проверка
python build_fops.py            # пересборка производных
git add SharedParameters.txt fops/
git commit -m "Добавлен параметр <ИМЯ> (<группа>)"
git push
```

## Как работает сверка семейств

Скрипт `check_fops.py` сравнивает GUID/имена/типы производных ФОПов с центральным:
если в фирменном ФОПе появился параметр, которого нет в центральном (или он
расходится по типу), — это ошибка. Файлы семейств (.rfa) проверяются выгрузкой
их параметров и сопоставлением GUID с центральным ФОПом.
