# Перенос темы «ФОП + FopTools» на другую машину

Подготовлено 20.10.2026. Тема хранится в этом репозитории; ветка `kimi-transfer-2026-10-20` добавляет эту инструкцию и промпт для Kimi.

## Быстрый старт на новой машине

1. Установить Git: https://git-scm.com/download/win
2. Установить .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
3. Склонировать репозиторий:

```bash
git clone https://github.com/prolojic/FOP.git
cd FOP
```

4. Проверить, что всё работает:

```bash
dotnet run --project FopTools -- check
```

Ошибок быть не должно (код выхода 0).

5. Открыть новый чат Kimi Work и вставить текст из `transfer/ПРОМПТ_ДЛЯ_KIMI.md` — в нём полный контекст темы и ближайшие задачи.

## Структура репозитория

| Путь | Что это |
|---|---|
| `SharedParameters.txt` | **Центральный ФОП** — единственный источник истины |
| `Upsite_vДДММГГ.txt` | Версии ФОПа Upside: `Upsite_v141026.txt` (базовая) и `Инструкция к ФОП.txt` — бывший `Upsite_v201026.txt`, описания заполнены; переименован 20.10.2026 |
| `fops/*.txt` | Производные фирменные ФОПы — **только генератором**, не править руками |
| `FopTools/` | Консольная утилита (C#, .NET 8): `build` — пересборка, `check` — валидация |
| `fop_rules.json` | Правила отбора параметров в фирменные ФОПы |
| `docs/` | Инструкция по работе через Git, каталог параметров (PDF) |
| `transfer/` | Инструкция по переносу и промпт для Kimi |

## Ключевые правила

- Файлы ФОП — в **UTF-16**, вручную не править; параметры добавляются только через Revit (Управление → Общие параметры → Изменить).
- GUID параметров после создания не меняются никогда.
- Перед работой `git pull`, после — `git push` и оповещение команды.
- Полный регламент — в `README.md`.
